# Telos — open intent

**Status:** distributed default — becomes human source on adoption

Telos is this project's sense of what is open: goals, desires and tracks,
short or long term. It is human ground. Agents read it, align day intent
against it, and propose changes; they never author it into being.

## Shape

    user/telos/<goal>/goal.md       why, done-when, non-goals
    user/telos/<goal>/tracks/*.md   bounded tracks: why, tickets, done-when

The root register keeps the same law at `Control/user/telos/`. The `/telos`
skill works at both registers: it aligns a day's intent entries against this
ground and gates NOW allocation on an aligned entry.
